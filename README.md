# Body Measure Lab — 身体寸法の視覚学習

## 主な機能
- トップバスト・アンダーバスト・ウエスト・ヒップのスライダーと数値入力
- 入力値に同期するモデルの模式変形
- 正面・斜め・側面・背面の4方向切り替え、前後ボタン、左右スワイプ
- 寸法差・ウエスト／ヒップ比の即時計算
- 比較プリセット、採寸ガイド、リセット、入力チェック
- 写真素材とJavaScriptを同梱し、外部CDN・外部画像読み込みに依存しない

## iPhoneで重要なこと
**チャット上のHTMLファイルをタップして開くiOSのファイルプレビューでは、JavaScriptが実行されない場合があります。** この環境ではAppleのQuick LookがJavaScriptを実行しないため、モデル画像が表示されてもスライダー連動は動きません。これはファイルの操作手順で解消できる不具合ではなく、プレビュー環境の制限です。

この版では、操作処理が停止する根本原因（描画用 canvas 要素の欠落）を修正し、Chromiumで操作を検証しています。ただし、この添付ファイルを開くiOS内蔵プレビューがJavaScriptを無効化する場合、プレビュー上では操作できません。その場合はHTTPSのWebサイトとして公開し、SafariでURLを開いてください。

## 検証結果（2026-10-14）
- スマホ幅390px、PC幅1440pxのブラウザ環境で検証。
- 正面・斜め・側面・背面の切替、スライダーと数値欄の同期、計算値の更新、canvas描画の変化、プリセット、リセット、採寸ガイドの切替を確認。
- JavaScript例外およびコンソールエラーなし。横方向のはみ出しなし。
- 実機iPhoneのSafariそのものでは未検証。

## ファイル
- `index.html`: 画像を内包した単体版。公開用に使えます。
- `site-template.html`: `assets/`内の画像を参照する編集用テンプレート。
- `assets/`: 高解像度の角度別画像とサムネイル素材。

この教材での画像変形は周径差を比較する模式表現です。実測値から人体を厳密に再構成したものではありません。
